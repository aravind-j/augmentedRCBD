# Generic functions for `augmentedRCBD` family

Generic functions for `augmentedRCBD` family

## Usage

``` r
describe(aug, ...)

freqdist(aug, ...)

gva(aug, ...)

report(aug, ...)
```

## Arguments

- aug:

  An object of class `augmentedRCBD`, `augmentedRCBD.menv` or
  `augmentedRCBD.mix`.

- ...:

  Unused.
